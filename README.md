# Отлив — кинематографичная сцена на Unreal Engine 5.8

**Unreal Scenes**, сцена 1 «Отлив» («Low Tide»). Вид от первого лица, около 9 минут, зритель — наблюдатель.

Посадочный модуль «Чайка» садится на планету, целиком покрытую водой по колено. Пилот идёт за дроном-разведчиком
«Светляк» к обломкам старого зонда «НЕВОД-2». Вода начинает уходить к горизонту, а «горный хребет» вдали оказывается
волной высотой 2 километра. Ясный пастельный день сменяется штормом, ливнем и темнотой — и волна накрывает корабль.

## Как посмотреть

Готовая сборка для Windows — в разделе **Releases** (архив `Otliv-Windows.zip`). Распаковать и запустить `Scenes.exe`.
Сцена начинается сама через пару секунд и идёт 9 минут 10 секунд со звуком. Камеру ведёт сюжет, а мышью можно
всё время крутить головой (влево-вправо до 150°, вниз до 70°, вверх до 80°).
Выход — Alt+F4. Рассчитана на компьютер с дискретной видеокартой (уровня RTX 2060 и выше; на мощной карте
не проверялась). На встроенной графике идёт рывками.

Черновой ролик со звуком: `Review/scene1/animatic/otliv_v3_sound_small.mp4`.

## Что внутри

| Папка | Что там |
|---|---|
| `Project/` | Проект Unreal Engine 5.8 (`Scenes.uproject`): уровень `/Game/Scene1/L_Otliv`, секвенс `SEQ_Otliv_RT`, материалы, звук. `Project/Scripts/scene1/` — Python-скрипты сборки сцены |
| `Models/` | Модели Blender: исходники `.blend` (`src`), скрипты сборки (`tools`), экспорт `.glb/.fbx` с текстурами и манифестами (`export`) |
| `Audio/scene1/` | Звук: скрипты синтеза окружения, эффектов и музыки, обработка голоса, тексты реплик, `CREDITS.md` |
| `Review/scene1/` | Ключевые кадры, раскадровки, проверочные снимки |
| `tools/ue_mcp/` | MCP-сервер для управления редактором Unreal через Python remote execution |
| `SCENE1.md` | Сценарий и техническое задание сцены |
| `CLAUDE.md` | Правила и заметки проекта |

## Как открыть проект

1. Установить Unreal Engine 5.8 (Epic Games Launcher).
2. Открыть `Project/Scenes.uproject`. Первый запуск долго компилирует шейдеры.

## Авторство и лицензии

Сценарий, модели, звук и код сделаны с нуля для этого проекта. Голос бортового компьютера — синтез Piper, голос
`ru_RU-dmitri-medium` (обучающие данные CC0); сама программа Piper в репозиторий не входит и скачивается скриптом
`Audio/scene1/tools/piper_get.sh`. Подробно — `Audio/scene1/CREDITS.md`.
