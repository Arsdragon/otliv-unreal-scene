# UnrealScenes — три кинематографичные сцены на Unreal Engine

Заказ пользователя (2026-11-19): три сцены по 7–10 минут, главное — визуал, зритель — наблюдатель, геймплея почти нет.
Сцена 1 — «Отлив» (`SCENE1.md`). Сцены 2 и 3 пользователь закажет позже.

## Кто есть кто

- **Режиссёр** — главный чат. Пишет ТЗ, принимает работу, общается с пользователем. Меняет `SCENE*.md` только он.
- **Чат «Модели»** — Blender, папка `Models\`.
- **Чат «Сцена N»** — Unreal, папка `Project\`, звук в `Audio\`, рендеры в `Renders\`.
- Под-чаты отчитываются режиссёру, а не пользователю. Вопросы и заказы друг другу — через режиссёра.
- Пишем по-русски: пользователь может открыть любой чат.

## Папки

- `SCENE1.md` — ТЗ сцены 1.
- `Models\tools` — скрипты сборки, `Models\src` — .blend, `Models\export\<id>\` — готовое для Unreal, `Models\shots` — рендеры на приёмку.
- `Project\` — проект Unreal (один на все сцены, уровень на сцену).
- `Audio\`, `Renders\`, `Review\` (кадры и ролики на приёмку).

## Машина — важно

- Ноутбук i5-13420H, 16 ГБ памяти, только встроенная Intel UHD, один диск C:, места мало.
- Памяти почти всегда в обрез. Одновременно держим одно тяжёлое приложение: либо Blender, либо Unreal.
  Перед тяжёлым запуском проверяй свободную память. Долгие команды (больше 2 минут) — в фоне.
- Имя пользователя в пути кириллицей (`C:\Users\Пользователь`). Всё проектное — только в `C:\UnrealScenes` (латиница).
- Команды Bash длиннее ~8000 символов обрезаются: скрипты пиши файлами.
- Не закрывать программы пользователя. Сетевые программы (VPN) не трогать никогда.
- Ничего не удалять вне `C:\UnrealScenes`. Чужие проекты (например, `Documents\Drift-Models`) можно читать, менять нельзя.
- Окна игр и редакторов без нужды не открывать; Blender по возможности без окна (`-b`).

## Правила

- Всё оригинальное: не копируем дизайн, реплики и музыку из фильмов и игр.
- Стиль пользователя: детальная реалистичная техника, не мультяшно и не «детская поделка»; интерфейсы спокойные, без неона.
- Не добавлять того, чего нет в ТЗ: идеи предлагать режиссёру одной фразой.
- Бесплатные текстуры из интернета брать можно, но в меру (слова пользователя 2026-11-22: «сильно не злоупотребляй»).
  Только свободные лицензии (CC0: Poly Haven, ambientCG), только там, где своя процедурная текстура заметно хуже;
  складывать в `Downloads\<источник>\` с записью лицензии; размер не больше 2K–4K, без гигабайтных наборов.
- Отчёт честный: что готово, что не проверено, что не получилось.

## Unreal

- Движок: Unreal Engine 5.8.4 в `C:\Program Files\Epic Games\UE_5.8`. Проект: `C:\UnrealScenes\Project\Scenes.uproject`
  (без C++, плагины Python, Editor Scripting, Sequencer Scripting, Movie Render Queue). Лог: `Project\Saved\Logs\Scenes.log`.
- Запуск: `"C:\Program Files\Epic Games\UE_5.8\Engine\Binaries\Win64\UnrealEditor.exe" "C:\UnrealScenes\Project\Scenes.uproject"`.
- **Видеокарта Intel UHD без 64-битных атомиков: DirectX 12 SM6 недоступен, редактор работает на DirectX 11 SM5.**
  Значит: нет Nanite, нет аппаратной трассировки лучей и Path Tracer. Есть Lumen (программный), каскадные тени,
  объёмные облака, Niagara, Single Layer Water, планарные отражения, Movie Render Queue. Сцену строим под это.
- Компиляция шейдеров: 4 воркера (`[DevOptions.Shaders]` в `Config\DefaultEngine.ini`). Первый запуск очень долгий.
- MCP: свой сервер `tools\ue_mcp\server.py` (без зависимостей, Python 3.13), подключён в `.mcp.json` как `unreal`.
  Инструменты: `ue_status` (редактор + свободная память), `ue_python` (Python внутри редактора), `ue_screenshot`
  (PNG вьюпорта или камеры прямо в чат, копия в `Review\_mcp`). Связь только через 127.0.0.1, после перезапуска
  редактора переподключается сама. Проверка без MCP: `python -I tools\ue_mcp\server.py --selftest 60`.
  Готовый `@runreal/unreal-mcp` отвергнут: при старте без редактора он завершался и не переподключался.
